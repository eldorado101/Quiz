Hey there! 

I built this little quiz because I wanted a fun, lightweight project to practice my vanilla JavaScript skills without reaching for React, Vue, or any heavy frameworks. 

It’s a simple trivia game testing your knowledge of HTML, CSS, and JS basics. I styled it to look like GitHub's dark mode because, well, it's what I stare at all day. 

###  What's under the hood?

No magic here, just the classic trio:
* **HTML5** for the structure (kept it semantic so screen readers and search engines are happy).
* **CSS3** for the styling (used CSS variables for the dark theme, no Bootstrap or Tailwind needed).
* **Vanilla JavaScript (ES6+)** for the logic. I had a lot of fun messing around with DOM manipulation and state management to handle the quiz flow, score tracking, and animations.
